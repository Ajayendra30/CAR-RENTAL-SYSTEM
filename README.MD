🚗 Car Rental System

A full-stack Car Rental Management System that allows users to browse available cars, book rentals, and manage reservations. The system includes an admin panel for managing cars, bookings, and users.

📌 Features
👤 User Features

User Registration & Login

Browse available cars

View car details (price, model, availability)

Book a car for selected dates

View booking history

🛠️ Admin Features

Add, update, delete cars

Manage bookings

View registered users

Monitor rental status
